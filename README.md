# Android Music Player (с синхронизацией через Telegram Бота)

Музыкальный плеер на **Kotlin + Jetpack Compose + Media3 (ExoPlayer)** с автоматической облачной сборкой APK через **GitHub Actions**.

## Возможности
- **Локальные треки:** чтение всех аудиофайлов из памяти телефона.
- **Гибкая очередь воспроизведения:** кнопки «Играть следующим», «В конец очереди», перемещение треков вверх/вниз без прерывания музыки, удаление из очереди.
- **Плейлисты:** создание своих плейлистов и добавление в них треков.
- **Системный эквалайзер:** настройка частотных полос в реальном времени.
- **Фоновое воспроизведение:** работает при выключенном экране и управляется из шторки уведомлений / с наушников.
- **Вкладка «TG Бот»:** прямая загрузка MP3/FLAC/M4A файлов, отправленных вашему боту в Telegram, прямо в память телефона (`Music/TelegramSync`).
